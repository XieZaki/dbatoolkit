# 常见故障排查

本文仅涉及本机 Windows 便携应用。开始时先记录 Toolkit 版本、CLI 安全错误类别和日志时间；不要复制或发送密码、连接串、原始凭据或包含敏感 SQL 的整份报告。

## 无法启动或缺少 Runtime

```powershell
.\dba.bat --version
.\dba.bat validate
.\dba.bat doctor
.\dba.bat runtime-info
```

确认从便携目录运行，目录内有 `runtime/python.exe`、`app/portable_entry.py`、`app/sql/`。若安全软件隔离了文件，从批准发行渠道重新下载并校验 Full ZIP；不要把 Runtime 文件从不明来源复制进来。将安装移到本机短路径后再试，避免 Windows 原生模块深层路径问题。

## 驱动未就绪

```powershell
.\dba.bat driver list
.\dba.bat driver check
.\dba.bat driver check --database sqlserver
.\dba.bat driver-info
```

检查 `docs/DRIVER_SETUP.md`。SQL Server 的 `pyodbc` 模块与 Microsoft ODBC Driver 是两个组件；需另行离线安装 ODBC Driver 17 或 18。Oracle 默认 Thin；不要因缺少 Instant Client 就误判 Thin 模式不可用。自定义驱动切换后出现导入错误，可使用：

```powershell
.\dba.bat driver rollback --database mysql
```

将 `mysql` 换成 `postgresql`、`oracle` 或 `sqlserver`。回退只切换对应数据库受管驱动，不删除已安装驱动包。

## Inventory 或资产错误

```powershell
.\dba.bat validate --json
.\dba.bat list
$DatabaseId = Read-Host '输入 database_id'
.\dba.bat show $DatabaseId
```

检查 YAML 缩进、资产 ID 唯一性、必需字段及 `credential_alias`。禁用资产可以显示但不能连接。不要在 Inventory 中添加 `password`、`token`、Secret 或带凭据连接串；验证错误可能只指出字段/位置，不回显原值。

## 数据库连接、版本或权限拒绝

```powershell
$DatabaseId = Read-Host '输入已审核的 database_id'
.\dba.bat test-connection $DatabaseId
.\dba.bat check $DatabaseId --json
```

确认只选中了预期测试/运维资产、主机和端口由本机管理员审核、DNS/防火墙/TLS/数据库服务可达。连接错误与 Collector 的数据库拒绝是不同问题。权限被拒绝时保留 Toolkit 给出的厂商错误类别并查阅 `docs/DATABASE_PERMISSIONS.md`；Toolkit 不会自动 GRANT，也不建议用管理员账号替代监控账号。

版本显示 Unsupported/Unknown 时，不要绕过 Version Profile 或尝试强制使用其他版本 SQL。收集脱敏后的产品版本和诊断场景，再按项目验收流程处理。

## 凭据无法解析

```powershell
.\dba.bat credentials backend
.\dba.bat credentials status
```

Windows OS 凭据通常与当前 Windows 用户关联。确认以创建/可访问凭据的同一 Windows 用户运行。缺少别名时使用 Toolkit 的隐藏提示/JIT 路径，不要把密码作为参数。SQLite 必须显式选择；解锁失败、文件损坏或目标 Store 不匹配时应停止，不要删除 Store、重置密码或自动迁移。需迁移时先查看 `docs/CREDENTIAL_SECURITY.md` 并按单独批准流程操作。

## HTML 报告未生成或无法打开

指定新文件名，避免覆盖已有报告：

```powershell
$DatabaseId = Read-Host '输入 database_id'
$ReportPath = Join-Path '.\reports' ('diagnose-' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '.html')
.\dba.bat diagnose $DatabaseId slow --report $ReportPath
Test-Path -LiteralPath $ReportPath
```

确认 `reports/` 可写且磁盘空间足够。HTML 是自包含文件，通常可离线打开；报告截断或部分采集时阅读其中完整性说明，不应把缺失证据解释为无问题。默认报告可能包含 SQL、对象和会话上下文，应只通过批准渠道传阅。

## Update ZIP 被拒绝或升级失败

确认安装根目录有 `portable-manifest.json`，Update ZIP 与该版本架构一致，`updates/` 中仅有一个匹配 ZIP，版本支持范围覆盖当前版本且没有 Toolkit 进程运行。先在发行渠道核对 SHA256。

升级器会保留 staging 与 `backup/program-backup-*`。若提示已自动恢复，检查旧版能否启动后再决定下一步；不要反复覆盖或清理备份。人工回退步骤见 `docs/UPDATE_GUIDE.md`。回退只恢复程序，不改用户数据。

## 只读操作说明

报告可能展示 `KILL`、`pg_cancel_backend`、`pg_terminate_backend` 或 Oracle KILL SESSION 参考文本。Toolkit 永不执行这些命令。不要从报告自动化复制执行；DBA 必须在原生客户端重新确认会话身份和当前影响后自行决定。
