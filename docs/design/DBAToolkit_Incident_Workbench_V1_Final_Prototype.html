DBA 检查项
01 · 应用与连接池
客户端主机 / IP / 端口、程序名、数据库用户、连接池等待、请求超时、应用端耗时和网络往返。
02 · CPU 与操作系统
数据库进程 CPU、系统 Run Queue、上下文切换、虚拟化 CPU Ready / Steal、NUMA 与 CPU 亲和性。
03 · 内存与临时空间
Swap / Paging、内存授予等待、PGA / Workarea、TempDB / 临时文件、排序与 Hash Spill。
04 · 存储与日志
数据盘与日志盘分开观察延迟、队列深度、吞吐、fsync；检查 redo / binlog / WAL 增长和 checkpoint。
05 · 事务与并发
最老事务、未提交事务、锁链、死锁、长时间快照、连接池突发和批处理并发。
06 · 复制与高可用
复制延迟、日志发送 / 接收 / 回放差距、复制槽或日志保留、同步提交等待和故障切换状态。
07 · 维护与后台任务
统计信息新鲜度、索引维护、Vacuum / Purge / Ghost Cleanup、备份任务、批量作业与定时任务重叠。
08 · 趋势与基线
对比同时间段历史基线，区分突发尖峰、持续退化和缓慢增长；保留诊断前后快照及采样完整性。
